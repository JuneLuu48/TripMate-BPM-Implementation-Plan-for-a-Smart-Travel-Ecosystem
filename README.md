## 📌 Project Overview

TripMate is a business process modelling and system design project that addresses the fragmented nature of modern travel planning. Travellers today must navigate multiple disconnected platforms — separate apps for flights, accommodation, restaurants, transport, and budgeting — creating a poor user experience and high planning friction.

This project applies **business process analysis, BPMN modelling, and design thinking** to redesign the travel planning journey into a unified, AI-powered smart travel ecosystem. It demonstrates end-to-end business analyst skills: from requirements gathering and current-state analysis through to future-state design and stakeholder-ready documentation.

---

## 🎯 Business Problem

**Current-state pain points identified:**
- Travellers use 5–7 separate platforms to plan a single trip
- No single source of truth for bookings, budgets, and itineraries
- Manual coordination between flight, accommodation, transport, and activity bookings
- No personalised recommendations based on past travel behaviour
- Poor real-time visibility of changes, delays, or cancellations

**Opportunity:** A unified smart travel platform that integrates all planning, booking, and navigation services into one seamless experience, powered by AI-driven personalisation.

## 🔧 Methodology

### 1. Requirements Gathering
- Applied **design thinking** and **empathy mapping** to understand traveller pain points and unmet needs
- Conducted stakeholder analysis to identify primary users, business owners, and system integration partners
- Documented functional and non-functional requirements for the TripMate platform

### 2. AS-IS Process Analysis
- Mapped the **current-state travel planning journey** using BPMN notation
- Identified key inefficiencies: manual data entry duplication, lack of integration between services, reactive (not proactive) travel support
- Performed gap analysis to identify where the current process fails to meet user and business needs

### 3. TO-BE Process Design
- Redesigned **6 core sub-processes** into an integrated future-state model:
  - Trip creation and itinerary management
  - Flight search, comparison, and booking
  - Accommodation and restaurant booking
  - Activity discovery and booking
  - Unified payment processing and confirmation
  - Real-time transport integration and navigation
- Modelled all processes using **BPMN 2.0 notation** in Draw.io

### 4. System Design & Prototype
- Defined system features aligned to redesigned processes: AI itinerary generation, budget management, loyalty tracking, real-time alerts
- Produced a **high-fidelity Figma prototype** to communicate the solution visually to stakeholders

## ✅ Key Outcomes

| Dimension | Current State | Future State (TripMate) |
|---|---|---|
| Platforms required | 5–7 separate apps | 1 unified platform |
| Booking coordination | Manual, user-managed | Automated, integrated |
| Personalisation | None | AI-driven recommendations |
| Real-time updates | Not available | Proactive alerts and notifications |
| Budget management | External spreadsheets | Built-in budget tracker |
| Transport integration | Separate navigation apps | In-app real-time transport |
